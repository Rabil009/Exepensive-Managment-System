# Contribution guide

1. Choose the feature folder you own under `frontend/src/features`.
2. Reuse the approved `ui` tokens, theme, components, patterns, and page templates.
3. Add only the folders and exports your feature needs. Keep page components thin.
4. Update design-system docs when changing shared tokens or component contracts.
5. Run `corepack pnpm install`, `corepack pnpm typecheck`, `corepack pnpm lint`, and `corepack pnpm build` before review.
